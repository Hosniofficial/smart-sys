# إدارة المنصة

تتوفر صفحات الإدارة العامة للمستخدم ذي دور `super_admin` فقط، وتعمل دون اختيار مستأجر:

- `/admin/tenants`: البحث في المستأجرين وتغيير حالتهم إلى `active` أو `trial` أو `inactive`.
- `/admin/audit`: سجل تغييرات إدارة المنصة فقط، وليس سجل عمليات المستأجرين.
- `/admin/operations`: فحص اتصال قاعدة بيانات التطبيق وعرض حالة نشر Railway والنسخ المجدولة/المتاحة لوحدات التخزين.

تغيير حالة مستأجر يتطلب سببًا، ويُسجل مع المستخدم المنفذ والحالة السابقة والجديدة في سجل التدقيق داخل معاملة واحدة. كما يسجل سجل المنصة تغييرات الاشتراكات والخطط التي يجريها المشرف العام، وفحوصات أمان الاشتراكات. لا تحذف صفحة المستأجرين المستأجرين أو بياناتهم. اختيار `inactive` يمنع استخدام سياق المستأجر عبر وسيط التحقق الحالي.

## إعداد قراءة Railway

تتكامل صفحة العمليات مع Railway GraphQL API باستخدام استعلامات قراءة فقط. لا تُنشئ النسخ الاحتياطية ولا تستعيدها؛ تُجرى هذه العمليات من Railway بعد مراجعة أثرها.

على خدمة API في Railway، أضف المتغيرات التالية:

| المتغير | القيمة |
| --- | --- |
| `RAILWAY_PROJECT_ACCESS_TOKEN` | Project Access Token مخصص ومقيد ببيئة الإنتاج |
| `RAILWAY_ENVIRONMENT_ID` | معرّف بيئة الإنتاج |
| `RAILWAY_API_SERVICE_ID` | معرّف خدمة التطبيق/API |
| `RAILWAY_DATABASE_SERVICE_ID` | معرّف خدمة MySQL |
| `RAILWAY_VOLUME_INSTANCE_IDS` | معرّفات وحدات التخزين مفصولة بفواصل؛ أضف وحدة MySQL ووحدة ملفات API إن وجدت |

لا ترسل الرمز إلى المتصفح، ولا تضعه في المستودع أو سجلات الطلبات. يُستخدم رأس `Project-Access-Token` من الخادم فقط. رغم أن التطبيق ينفذ استعلامات قراءة، يجب التعامل مع الرمز كسِرّ ذي صلاحيات Railway وحصر نطاقه في البيئة المطلوبة.

إذا لم تُضبط المتغيرات، تعرض الصفحة حالة `غير مهيأ` وأسماء الإعدادات الناقصة. تُحدّث البيانات يدويًا لتجنب polling غير الضروري للـAPI. تعرض الصفحة حالة النشر ومواعيد النسخ والجداول وأحجامها/انتهاء صلاحيتها، ولا تعرض أسرار Railway أو سجلات التشغيل.

مصادر API الرسمية:

- [Railway Public API](https://docs.railway.com/integrations/api)
- [Manage Volumes and Backups](https://docs.railway.com/integrations/api/manage-volumes)
- [Manage Deployments](https://docs.railway.com/integrations/api/manage-deployments)
