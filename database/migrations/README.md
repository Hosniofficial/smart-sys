# Database Migrations

تحتوي `database/migrations/` على سجل تغييرات المخطط والبيانات. الملفات مرقّمة ويطبّقها runner الرسمي بالترتيب، مع تسجيل ما نُفّذ في جدول `migrations`.

```powershell
php database/migrate.php status
php database/migrate.php up
```

افحص `status` أولًا، ولا تشغّل `up` إلا على قاعدة تطوير أو اختبار معزولة وبعد مراجعة الملفات المعلقة. قبل أي تغيير على قاعدة قائمة، يلزم التحقق من سجلها وأخذ نسخة احتياطية قابلة للاستعادة. لا تشغّل ملفات migration يدويًا، ولا تعدّل أو تحذف أو تعِد ترقيم migration سبق تطبيقها؛ أضف migration جديدة للتصحيح.

لا تُحفظ حزم استيراد أو نسخ احتياطية في المستودع. راجع [تعليمات قاعدة البيانات](../README.md) قبل إجراء أي تغيير على قاعدة مشتركة أو إنتاجية.
