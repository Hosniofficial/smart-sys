# قاعدة البيانات

يحتوي هذا المجلد على ملفات migrations وأدوات تشغيل قاعدة البيانات العامة. أزيلت ملفات النسخ التاريخية وأدوات النقل والترحيل الخاصة بمزودي الاستضافة بعد نقل قاعدة الإنتاج والتحقق من استعادتها؛ لا توجد dumps هنا.

## migrations

تحتوي `migrations/` على migrations المرقمة. لا تحذفها أو تعِد ترقيمها؛ يعتمد عليها سجل التطبيق وإعادة بناء قواعد جديدة. افحص الحالة قبل التشغيل:

```powershell
php database/migrate.php status
```

لا تشغّل `up` إلا على قاعدة تطوير أو اختبار معزولة وبعد مراجعة migrations المعلقة. قبل أي تغيير على قاعدة قائمة، تحقق من سجلها وخذ نسخة احتياطية قابلة للاستعادة. لا تشغّل migrations على قاعدة استُعيد إليها dump كامل يحتوي سجلها.

تتطلب migrations المعلّمة `REQUIRES_BACKUP_CONFIRMATION` تأكيدًا صريحًا ومعرّف نسخة احتياطية:

```powershell
php database/migrate.php up --confirm-irreversible --backup-reference=backup-id-2026-10-27
```

لا تستخدم هذا الخيار قبل استعادة النسخة في بيئة اختبار والتحقق منها. يحتفظ سجل نشر الأوامر بمعرّف النسخة؛ الخيار يضيف حاجزًا تشغيليًا ولا ينشئ نسخة احتياطية بنفسه.

للاتصال بخادم بعيد عبر TLS، مرر إعدادات الهدف عبر متغيرات العملية `DB_*`، واضبط `DB_SSL_CA` إلى شهادة CA؛ يتحقق runner من شهادة الخادم افتراضيًا عند استخدام CA.

تحتوي migrations الأخيرة على تغييرات لأوامر صيانة الأجهزة، وصلاحيات الفروع والمستأجرين، وعروض الأسعار وحملات الأسعار. راجع ملفات migration نفسها لمعرفة تفاصيل كل تغيير.

Migration `040` تضيف علاقات مرجعية محددة، وتوحد أنواع بعض أعمدة الربط، وتزيل تعليقات الأعمدة من الجداول المحددة. وهي تحفظ السجلات التاريخية، ولا تفصل إلا المراجع اليتيمة المعروفة محليًا بعد التحقق من أرقام السجلات والمراجع المتوقعة.

Migration `041` تحذف أعمدة قديمة ثبت خلوها من البيانات وعدم استخدامها أو اعتماد أي فهرس/قيد/عرض/مشغل/إجراء مخزن/حدث مجدول عليها. تتوقف قبل أي حذف إذا وجدت بيانات أو اعتمادًا على أحد الأعمدة، وتتطلب تأكيد نسخة احتياطية قابلة للاستعادة عبر المشغّل.

Migration `042` تزيل آخر تعليق عمود مطلوب في `cash_vouchers`، وتوحّد أوصاف الصلاحيات المحددة إلى الإنجليزية مع إبقاء `display_name` بالعربية. تتحقق من القيم الحالية قبل التعديل.

Migration `043` تضيف العلاقات المرجعية الأربع المتبقية التي أمكن التحقق من دلالتها وسلامة بياناتها: فرع المورد، ومستأجر وحدات المنتجات وتفاصيل المبيعات، وقاعدة تحديد المعدل. توائم نوع `suppliers.branch_id` مع نوع مفتاح الفروع قبل إضافة العلاقة.

Migration `044` تحذف `products.is_active_product` المكرر فقط إذا تطابقت قيمه مع `products.active` ولم يوجد اعتماد غير متوقع عليه؛ وتزيل فهرسه المنفرد. كما توحّد تنبيهات انتهاء الصلاحية مع جدول `product_expiry` الذي تستخدمه عمليات الشراء والمرتجعات. تتطلب تأكيد النسخة الاحتياطية لأنها لا تعيد العمود عند rollback.

Migration `045` تحذف جداول `documents`, `payment_transactions`, `user_preferences`, و`account_device_associations` بعد رفض التنفيذ إذا احتوى أي منها بيانات، أو وجد مرجع أجنبي وارد، أو اعتماد في عرض/مشغل/إجراء/حدث مجدول. تتطلب تأكيد النسخة الاحتياطية لأنها غير قابلة للعكس. أزيل من وسيط الاشتراك فحص عدد الحسابات المرتبطة بالجهاز الذي لم يكن له أي مسار كتابة؛ وتبقى فحوص بصمة الجهاز ومخاطرها الأخرى.

بيانات التهيئة الحالية موجودة في قاعدة Aiven المنقولة. لا تحفظ نسخًا تشغيلية أو dumps أو بيانات اعتماد داخل المستودع.
